# About this page

Import shipments — consignments on the water with their landed cost (goods + freight + duty).

## Lifecycle
Ordered → In transit → Customs → Cleared → Received. The arrow on each row moves a shipment to the next stage; open the shipment for the full journey and landed-cost breakdown.

The chips count shipments still on the water and the landed value outstanding.
