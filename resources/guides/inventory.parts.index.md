# About this page

The master list of every part in the catalogue. The search covers part numbers, OEM numbers, barcodes, descriptions and cross-references — one box finds it whatever number you have.

## How it works
- Scan a barcode straight into the search box.
- An amber **→ number** under a part means it is superseded — sell the replacement.
- **Available** is on-hand minus reserved, across all branches.

## Watch out
- A part must have a category and unit before it can be created; keep descriptions consistent ("Oil Filter — <vehicle>") so searches stay predictable.
