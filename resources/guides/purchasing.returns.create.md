# About this page

Start a return to a supplier. Nothing leaves stock until the return is **shipped** with an RMA number.

## How it works
- The **reason** pre-sets each line's condition (damaged → damaged, wrong part → new, warranty → used); adjust per line.
- The picker shows **on-hand at the chosen branch** and warns if a line returns more than held — `3*CODE` adds multiples.
- Condition matters: "new" items can go back at full cost; damaged/used negotiate lower.
