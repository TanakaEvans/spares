# About this page

VAT returns for a period, computed **live from the ledger** — Output VAT (account 2210) less Input VAT (2220) equals the net payable. Nothing is cached, so a return always ties back to the journals behind it.

## Filing
Pick the period to see the live preview, then **Generate** a return (draft). Move it draft → submitted → paid as you file and settle with the revenue authority. Corrections are made with a journal, never by editing a filed return.
