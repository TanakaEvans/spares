# About this page

Physical stock counts and their variance resolution. A stock take freezes a **system snapshot**, you count, then the difference posts as a single stock adjustment through the ledger.

## The count cycle
1. **Start** a full (whole branch) or spot (chosen parts) count — this snapshots system quantities.
2. **Count** — enter the physical quantity for each line.
3. **Lock & review** the variance; large variances are flagged for a recount.
4. **Post** — the net difference books as one adjustment (shortages write off, surpluses write on).

## Watch out
- Uncounted lines are treated as no change — count everything before posting a full take.
- Posting is final; corrections need a fresh count or a manual adjustment.
