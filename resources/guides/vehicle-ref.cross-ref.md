# About this page

The customer hands you ANY number — OEM, GUD, Mann, a barcode, a competitor's code — and this search finds your part. Every number a part is known by lives in its cross-references.

## How it works
- Matches part numbers, OEM numbers, barcodes, descriptions AND every cross-reference.
- **Superseded numbers resolve automatically**: search the old number, get an amber banner pointing to the replacement.
- Stock shows live: green means it is on the shelf.

## Watch out
- No match? The number may not be cross-referenced yet — add it on the part's Cross-refs tab so the next search succeeds. That is how the catalogue learns.
