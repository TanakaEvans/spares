# About this page

Returns to supplier — damaged, incorrect or excess stock going back for credit. The chips show what's waiting to ship and what's waiting on the supplier's credit.

## Lifecycle
Draft → **Ship** (supplier's RMA number required — stock leaves the shelf and AP accrues) → **Capture credit** (the supplier's credit note reduces what you owe) → Credited.

The money only moves when the credit is captured — chase shipped returns showing in the chips.
