# About this page

Every posted tax invoice. Invoices are immutable — a mistake is corrected with a **credit note**, never an edit.

## On an invoice
- Print an **A4 tax invoice** or an **80mm receipt**.
- Raise a **credit / return** against any line that still has creditable quantity.
