# About this page

Promotions &amp; discounts — percent or rand-off specials, across all parts or one category, inside a date window.

- Status follows the dates: **scheduled** before it starts, **live** inside the window, **ended** after. **Disable** switches it off without deleting.
- Values are a percentage or a rand amount depending on the type chosen.
