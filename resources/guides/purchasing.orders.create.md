# About this page

Draft a purchase order — a request to the supplier that becomes receivable once submitted.

## How it works
- Pick the **supplier first**: their price-list cost pre-fills each line, and the expected date defaults to today + their lead time.
- Search parts like the till: part number or description words; `3*CODE` adds three at once.
- An unfinished draft survives a refresh until you save. **Ctrl+Enter** creates the draft PO.

Saving creates a **draft** — nothing is promised yet. Submit it from the order's page to send it to the supplier.
