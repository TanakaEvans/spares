# About this page

Build a formal quotation — a priced offer that reserves no stock and expires on a set date.

## How it works
- Search parts like the till: vehicle + part type, part number, or `3*CODE`.
- The customer's price list sets each line's price; changing the customer re-prices the lines.
- Availability is informational only — nothing is reserved until the quote converts to an order.

The quote stays valid for the configured number of days (shown next to the total). An unfinished quote survives a refresh; **Ctrl+Enter** saves.
