# 6.2 Supplier Price Lists

> Imports and maintains supplier catalogue cost prices that drive POs and stock valuation. Part of [Module 6: Supplier Management](../06-supplier-management.md).

## Purpose

Suppliers publish price updates constantly — a filter distributor may issue a new catalogue monthly, an importer quarterly with exchange-rate-driven changes. The business needs those cost prices in the system, matched to its own part numbers, before buyers raise purchase orders; otherwise POs go out at stale prices, invoice matching fails, and margin calculations lie. This sub-module owns the pipeline from "supplier emailed an Excel catalogue" to "active price list feeding cost prices onto POs".

The hard problem is part matching. The supplier's catalogue uses *their* part numbers (an NGK plug is `BPR6ES` to NGK, something else to a wholesaler); the import process maps their columns to our fields and resolves their numbers to our internal parts through the cross-reference table maintained in Inventory. Unmatched rows are the buyer's review queue — some are genuinely new parts worth stocking, some are noise.

The second problem is change control. A new price list can move hundreds of costs at once; buyers must see the deltas (previous price, new price, % change) *before* activation, because a 40% jump on a fast-moving line may mean renegotiating or switching to the secondary supplier (6.3) rather than accepting it silently into selling-price calculations.

## User Roles & Permissions

| Role | Access |
|------|--------|
| Buyer | Upload catalogues, map columns, resolve matches, review deltas |
| Purchasing Manager | Activate/supersede price lists; approve imports with large average increases |
| Inventory Controller | Maintain part cross-references used by matching |
| Accounts Payable Clerk | View active prices (for invoice-price queries) |
| System Admin | Delete failed/abandoned pending imports |

## Workflow

Main process: import and activate a supplier price list.

```
Supplier sends Excel/CSV catalogue
        │
Upload file → choose supplier, currency, effective date
        │
Column mapping (their columns → our fields)
[saved as reusable mapping template per supplier]
        │
Match rows: supplier part number → our part
(via cross-reference; exact → alias → manual)
        │
   ┌────┴─────┐
matched      unmatched ──> review queue:
   │              ├─ link to existing part (adds cross-ref)
   │              ├─ create new part (Inventory flow)
   │              └─ skip (not stocked)
   ▼
Delta review: old cost vs new cost, % change per line,
sorted by impact; flags > threshold highlighted
        │
Purchasing Manager activates ──> status `active`,
previous list → `superseded`
        │
New POs pick up new costs; open unconfirmed POs untouched
```

1. **Upload.** Excel/CSV up to 50k rows; the file is parsed and previewed before anything is written.
2. **Map columns.** First import per supplier defines the mapping (part number, description, price, MOQ, discount columns); the mapping is saved and pre-applied on the next import.
3. **Match.** Exact cross-reference hits auto-match; near matches (normalised: stripped dashes/spaces/case) are suggested; the rest queue for manual resolution. Manual links write back to the cross-reference so next month's import matches automatically.
4. **Review deltas.** The system compares against the currently active list and presents every change; increases above a configured threshold (default 15%) require explicit per-line acknowledgement or Manager approval.
5. **Activate.** One click supersedes the previous list; effective/expiry dates control when prices apply.

## Screens

| Screen | Route | Purpose |
|--------|-------|---------|
| Price lists | `suppliers.pricelists.index` | All lists by supplier with status and dates |
| Import price list | `suppliers.pricelists.import` | Upload, mapping, matching, delta review wizard |
| Price list detail | within index | Line items, deltas vs predecessor, activation history |

**Primary screen — Import wizard (`suppliers.pricelists.import`):**
- **Header:** stepper (Upload → Map → Match → Review → Activate), supplier and list name, row counts (total / matched / unmatched / skipped).
- **Main area:** step-specific — mapping grid with sample rows; match-resolution queue with suggested parts; delta table (part, old cost, new cost, %Δ, annual usage, margin impact) sortable by impact.
- **Actions:** Save Draft (resume later), Download Unmatched as Excel, Acknowledge Flagged Lines, Activate (Manager).

## Fields & Validation

Import header and line handling:

| Field | Type | Required | Validation rules |
|-------|------|----------|------------------|
| Supplier | FK select | Yes | Active supplier |
| Name | text(100) | Yes | e.g. "NGK Jan 2026 Pricelist"; unique per supplier |
| File | upload | Yes | .xlsx/.csv, ≤ 20 MB, ≤ 50,000 rows |
| Currency | FK select | Yes | Must equal supplier's currency; mismatch blocks import |
| Effective date | date | Yes | ≥ today − 30 days |
| Expiry date | date | No | > effective date |
| Cost price (per line) | decimal(15,2) | Yes | > 0; rows with 0/blank/non-numeric price are rejected with row numbers |
| Supplier part number (per line) | text(100) | Yes | Non-blank; duplicates within the file rejected (last-wins is never silent) |
| Minimum qty (per line) | decimal(10,2) | No | ≥ 0 |
| Discount available (per line) | decimal(5,2) | No | 0–100 |

## Business Rules

1. Only one price list per supplier may be `active`; activation atomically supersedes the predecessor (parent rule) — there is never a window with two active lists or none.
2. Prices on open **unconfirmed** POs are not retroactively updated (parent rule); *confirmed* POs are never touched, and the receiving/matching flow compares invoice price to the PO price, not to the current list.
3. Every import logs the full delta set (previous, new, % change) permanently — activation approvals reference this snapshot.
4. Increases above the review threshold require per-line acknowledgement or Purchasing Manager approval before activation can complete.
5. A part on the active list but missing from the new list keeps no price after supersession: the buyer sees it in the delta review as "discontinued by supplier" and must acknowledge; it also flags on the approved supplier list (6.3).
6. Foreign-currency lists store costs in the supplier's currency; conversion to local currency for valuations uses the exchange rate at transaction time (PO/GRN), never at import time.
7. Manual match decisions write cross-reference records owned by Inventory; unmatched rows never invent parts silently — new parts go through the standard part-creation flow.
8. Draft imports older than 60 days are auto-flagged stale and cannot be activated without re-validation against the current active list.

## Edge Cases & Error Handling

- **Supplier changed their column layout:** the saved mapping fails validation on preview (mapped columns missing); the buyer remaps and the new template saves — the import never guesses.
- **Same supplier part number maps to two of our parts:** cross-reference conflicts stop auto-match for that row and force a manual pick; the conflict is reported to the Inventory Controller to clean up.
- **Catalogue includes 3,000 parts we don't stock:** bulk "skip remaining unmatched" is available after review of the first page; skipped rows are retained on the list record (not imported as items) so "what else do they sell" queries remain answerable.
- **Price given per box of 10, ours per unit:** the mapping step supports a pack-size divisor column/constant; delta review makes unit-cost errors obvious (−90% or +900% lines top the impact sort).
- **Activation attempted while a PO is being drafted:** the PO picks up whichever list is active at the moment a line is added; lines already on the draft keep their captured cost — a banner on the PO warns that a newer list activated mid-edit.
- **Import uploaded against the wrong supplier:** pending imports can be deleted (Admin/Buyer-own); activated lists cannot — the fix is activating a corrected list, keeping the audit trail honest.
- **Expiry date passes with no replacement list:** the list stays `active` but the price-list screen and PO lines show an "expired prices" warning; reorder suggestions flag the supplier for a catalogue chase (6.5 contact).

## Key Tables

- `supplier_price_lists` — list header: supplier, dates, currency, status (schema in [Module 6](../06-supplier-management.md#62-supplier-price-lists)).
- `supplier_price_list_items` — per-part cost, supplier part number, MOQ, discount.
- Part cross-reference table — supplier part number ↔ internal part (owned by Inventory; written to by the match step).
- Import mapping templates and delta-log tables — per-supplier column mappings and price-change snapshots.
