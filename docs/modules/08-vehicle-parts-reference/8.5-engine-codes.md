# 8.5 Engine Codes

> Reference list of manufacturer engine codes — the fastest reliable way to identify a vehicle for parts. Part of [Module 8: Vehicle & Parts Reference](../08-vehicle-parts-reference.md).

## Purpose

For service parts (filters, belts, plugs, gaskets, injectors) the engine matters more than the badge on the tailgate. A Hilux, a Fortuner, and a Land Cruiser Prado all take the same oil filter when they share the 1GD-FTV engine. Customers and mechanics frequently know the engine code — it is stamped on the block and printed in the service book — even when they are vague on trim or year. A searchable engine-code reference lets staff jump straight from "it's a 1GD" to the correct variants and their parts.

The table also anchors data quality: variant records ([8.2](8.2-vehicle-models-variants.md)) store an `engine_code` string, and this reference is the controlled vocabulary that string should match. Codes carry their own spec (capacity, fuel, aspiration, cylinders, valves) so a variant entered with a mismatched spec — a "1GD-FTV petrol" — can be caught automatically.

Seed data covers the engines dominant in the Southern African parc: Toyota 1GD-FTV/2GD-FTV/2TR-FE/1KZ-TE, VW EA888/CAYB, Ford Duratorq/EcoBoost, Isuzu 4JJ1/4JK1, and the older Corolla 4A-FE/5A-FE workhorses, per the parent doc's seeded list.

## Workflow

```
[Mechanic phones: "glow plugs for a 1GD"]
            │
            ▼
   [Engine code search: "1GD"]
            │
            ▼
   [1GD-FTV — Toyota 2.8L diesel, turbo, 4 cyl]
            │
            ├──► [Variants using this engine: Hilux 2.8 GD-6,
            │     Fortuner 2.8, Prado 2.8 (2015+)]
            │
            └──► [Jump to fitment results for a chosen variant]
```

1. **Search** — partial-code search ("1GD", "4JJ") with make filter.
2. **Inspect** — code detail shows description, capacity, fuel, aspiration, cylinders, valves, notes, and the list of variants referencing it.
3. **Pivot to parts** — from the code, select a variant and land in the [Fitment Guide](8.4-fitment-guide.md) pre-filtered.
4. **Maintain** — data admins add codes as new models enter the market; the variant form's autocomplete draws from this list.

## Fields & Validation

| Field | Type | Required | Validation rules |
|-------|------|----------|------------------|
| code | text | Yes | max 30; unique per make (same code string can exist under two makes) |
| make_id | select | Yes | active make |
| description | text | Yes | max 255, human summary e.g. "Toyota 2.8L diesel, direct injection, turbo" |
| capacity_cc | integer | No | 50–20000 |
| fuel_type | select | No | petrol/diesel/hybrid/electric/lpg |
| aspiration | select | No | naturally_aspirated/turbo/supercharged |
| cylinders | integer | No | 1–16 |
| valves_per_cylinder | integer | No | 2–6 |
| notes | text | No | free text (recall notes, family info, e.g. "EA189 — emissions-scandal engine, high demand for EGR parts") |

## Business Rules

1. Codes are stored uppercase and matched case-insensitively; hyphens are preserved for display but ignored in search ("1GDFTV" finds "1GD-FTV").
2. Uniqueness is per make, not global — different manufacturers can reuse short code strings.
3. An engine code cannot be deleted while any `vehicle_variants.engine_code` references it; deactivate instead.
4. Editing a code's spec (capacity, fuel) triggers a consistency re-check against all variants using it; mismatches are listed for the admin before saving.
5. Engine *families* marketed under one name (Ford "Duratorq" covers 2.2 and 3.2 TDCi) may be entered either as one family record with notes or as separate records per displacement — separate records are preferred once fitment differs between displacements.
6. Codes belong to reference data, not stock: nothing prices or sells against an engine code directly.

## Edge Cases & Error Handling

- **Variant saved with an unknown engine code**: allowed (typed free), but flagged on the data-quality widget; the admin either creates the code or corrects the variant.
- **Same engine across makes** (badge-engineered vehicles, e.g. Mazda BT-50 sharing Ford Duratorq): create the code under each make it is sold under, with a cross-note; search by code returns both.
- **Customer reads a casting number, not the engine code**: no match — the detail screen's notes field can list common casting-number confusions for high-volume engines; staff fall back to make/model lookup.
- **Family code searched where displacements differ** ("EcoBoost"): result lists all EcoBoost records; staff must pick displacement before pivoting to parts.
- **Code renamed by manufacturer mid-life**: keep the original record and add the new spelling to the notes; do not rename in place while variants reference it.
- **Ambiguous partial search** ("4A" hits 4A-FE and 4AGE if both seeded): standard result list, no auto-select.
