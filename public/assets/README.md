# Public Assets Directory Structure

This directory contains all public assets for the School Portal application.

## Directory Structure

- `/images/` - Static images
  - `/logos/` - School logos and branding
  - `/banners/` - Hero banners and promotional images
  - `/avatars/` - Default avatar images
  
- `/documents/` - Public documents
  - `/policies/` - School policies and guidelines
  - `/forms/` - Downloadable forms
  
- `/downloads/` - General downloadable files

## Usage

All files in this directory are publicly accessible via the web server. 
Place assets in appropriate subdirectories for organization.

Example URLs:
- School logo: `/assets/images/logos/school-logo.png`
- Policy document: `/assets/documents/policies/student-handbook.pdf`
- Downloadable form: `/assets/documents/forms/enrollment-form.pdf`
